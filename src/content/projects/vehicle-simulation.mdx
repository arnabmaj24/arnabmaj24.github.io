## Why

A sway controller is hard to develop on a real truck: you can only provoke so much sway safely, and every run costs a day. I wanted a model good enough to try controller changes on first and only take the promising ones to the road.

## The model

I built it up in steps. It started as a kinematic bicycle model in Python, then became a dual-track model with tire dynamics, then moved to C++, and then to Rust (about 3,200 lines), with a Python front end for plots and animations.

The tow vehicle and the trailer are rigid bodies on Fiala tires. The hitch is a rigid joint: each step solves for the constraint forces through S = J M⁻¹ Jᵀ (a 2×2 matrix, inverted analytically), and Baumgarte stabilization stops the joint from slowly drifting apart.

## Does it match reality?

I tuned the model's parameters from field logs, then compared the IMU readings it predicts with the ones measured on the real system over 8,000 km of testing, mainly accelerations such as the deceleration a given brake command produces. The fit is R² = 0.93.

## One code path

The simulator depends on the production control-loop crate, so it runs the firmware's own sway controller, not a re-implementation of it: simulated IMU data goes in, and the controller's brake command goes back into the model. Separate binaries render animations, run batch parameter sweeps and compare controllers.

## Trying something better: MPC

I used the simulator to prototype a nonlinear model predictive controller for sway braking. In double-lane-change runs it settled sway 2.2× faster than the shipped controller, in simulation. The image above is one frame from that comparison: with the same steering input, the uncontrolled trailer is at −8.1° of hitch angle while the MPC-assisted one is at −0.7°. The MPC hasn't been to the road yet.

For a hands-on version, the [sway demo](/sway-demo) runs a much simpler truck-trailer model in your browser: change the speed and tongue weight and watch a sway controller catch the sway. It's a separate, simplified model, not this simulator.
